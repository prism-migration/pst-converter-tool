An enterprise-grade, standalone desktop migration engine engineered to convert Microsoft Outlook PST files into multiple email formats, documents, and cloud platforms without requiring Microsoft Outlook to be installed.

---

## 🚀 Key Features

- **Zero Outlook Dependency**: Process ANSI and Unicode PST files (up to 100 GB) without Outlook installed.
- **17+ Export Formats**: Convert PST to MBOX, EML, MSG, PDF, HTML, MHTML, RTF, TXT, DOC, vCard (VCF), and iCalendar (ICS).
- **Direct Cloud Migration**: Migrate emails directly to Microsoft 365 (Office 365), Gmail, Google Workspace, and IMAP servers via modern OAuth 2.0.
- **Advanced Filtering Engine**: Filter items by Date Range, Sender, Recipient, Subject keywords, and Folder hierarchy.
- **Duplicate Removal**: Automatically filter out duplicate emails based on Message-ID, Subject, and Timestamp.
- **Attachment Integrity**: Preserves original email headers, metadata, inline images, and attachments.
- **Legal PDF Conversion**: Export PST to searchable PDF with embedded or detached attachments.
